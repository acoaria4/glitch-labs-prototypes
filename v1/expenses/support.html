Support

Expenses by gLitCh Labs
App ID: com.glitchlabs.expenses
Last updated: 8 August 2026

Need help with Expenses? Use the options below. The app is local-first by default; optional sign-in adds cloud sync and shared groups across devices. Before reinstalling or clearing app storage, export a backup of any local data you want to keep. See the common fixes below, or send us a report.

1. Report a bug or ask a question

Open an issue on GitHub (preferred): github.com/acoaria4/expenses-by-glitchlabs/issues

Include your device model, OS version, and app version (Settings → About) when possible.

2. Delete your account

To delete a signed-in Expenses cloud account and associated cloud data, follow the steps on the Delete account page (email glitchlabsio@gmail.com).

3. Common fixes

  • Lost data after reinstall — if you were signed in, sign in again to restore the synced vault; otherwise restore from a JSON backup in Settings if you exported one earlier.
  • Keyboard covering a field — dismiss and refocus the field, or update to the latest version from the store / TestFlight.
  • Data missing on another phone — local-only use does not sync; sign in on both devices if you want cloud sync.

4. Privacy

Read the Privacy Policy for on-device data, optional cloud sync, and deletion requests.
